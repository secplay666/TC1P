# 微光 App 本地交互原型

打开方式：

```text
直接双击 index.html
```

或在浏览器中打开：

```text
design/prototype/index.html
```

本原型是纯静态 HTML/CSS/JS，不依赖网络、不需要构建。它用于讨论产品结构和交互，不代表正式 Android 代码结构。

当前可点击内容：

- 启动页：进入 App。
- 附近页：扫描、查看附近用户、打开资料预览。
- 资料预览：问候、聊天、屏蔽。
- 消息页：进入聊天。
- 聊天页：发送消息、模拟发送失败、重试。
- 我的页：可见性与终端状态。
- 安全页：隐身、接收陌生问候、只接收强信号。
- 诊断页：从“我的”页进入，模拟调试字段。
