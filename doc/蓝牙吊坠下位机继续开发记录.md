### 2.3 迁移 DRV2625 电机驱动

已重写：

- `tc_ble_single_sdk/vendor/ble_sample/pendant/motor/app_motor.c`

当前电机模块已接入 DRV2625 I2C：

- I2C 引脚：PB6 / PD7。
- TRIG 引脚：PB5。
- DRV2625 7-bit 地址按 `0x5A` 处理，Telink I2C ID 使用 `0xB4`。
- I2C 目标频率：200 kHz。
- 初始化时执行旧代码中的自动校准参数：
  - `MODE = 0x48`
  - `MODE = 0x4B`
  - `CONTROL1 = 0x80`
  - `RATED_VOLTAGE = 0x46`
  - `OD_CLAMP = 0x5C`
  - `DRIVE_TIME = 0x10`
  - `GO = 0x01`
- 支持 `MOTOR_PATTERN_ONE/TWO/THREE/ERROR`。
- `app_motor_play()` 改为 I2C 写波形并触发 `GO`。
- 使用软件 busy 计时防止振动重入。
- 支持配置项 `vibration_enable`。

6. 两块板互扫，确认 `app_scan -> app_adv_proto -> app_discovery` 链路走通。
7. 调整两块板距离，验证 S1/S2/S3 和 1/2/3 次马达提示。
