# 微光隐私与资料卡编辑修复记录

日期：2026-06-28

## 本次修改

1. 完成“隐私与安全”中的隐身模式和屏蔽列表基础能力。
   - App 侧保存隐身模式偏好，并通过资料卡 visible flag 同步到 B85 终端。
   - App 侧保存屏蔽列表，附近页、消息页、头像同步、文件/消息接收和发送入口都会过滤已屏蔽对象。
   - “我的 -> 隐私与安全 -> 屏蔽列表”支持从最近对话和附近终端中选择屏蔽/解除屏蔽。

2. 修复隐身后对端附近页仍能看到的问题。
   - 附近页只展示已解析到的资料卡，不再把底层 raw peer 直接渲染成用户卡片。
   - B85 扫描到同一 EID 的无资料卡 Beacon 后，会移除旧的 profile cache，避免旧昵称/签名残留。
   - 增加 debug-only privacy 广播和 `GlimmerPrivacy` 日志，便于验证 raw peer 与资料卡展示的差异。

3. 修复编辑附近预览卡片时输入法跳走的问题。
   - 资料卡编辑页中昵称/签名输入框获得焦点时，后台同步只刷新顶部状态，不重建内容区。
   - 避免 `EditText` 被后台同步回包重建，从而保持输入法、光标和正在输入的内容。

## 验证结果

1. Android 构建通过：
   - `.\gradlew.bat assembleDebug`

2. 固件构建通过：
   - `powershell -ExecutionPolicy Bypass -File .\tools\build_pendant_multi.ps1`

3. 实机验证：
   - APK 已安装到 Pixel 和华为手机。
   - COM16 与 COM10 已刷入最新 B85 固件。
   - 华为绑定的 COM10 开启隐身后，Pixel 侧 raw peer 仍能看到 `C4C4154A`，但附近资料卡列表从 3 位降为 2 位，不再显示 `lantern`。
   - 退出隐身后 `lantern` 恢复显示；重新进入隐身后再次消失。
   - Pixel 上编辑资料卡签名时触发后台刷新，输入法仍保持显示，光标和输入内容未丢失。

## 设计说明

当前隐身模式是产品层隐身，不是无线静默模式。B85 底层仍会广播和扫描 raw peer，以维持发现、P2P 和后续通信能力；App 附近页只展示可见资料卡，因此用户层不会看到已隐身终端。
