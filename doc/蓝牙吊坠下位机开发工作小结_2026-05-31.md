## 5. 重要临时实现

以下内容是为了尽快搭起第一阶段闭环，后续必须替换或完善。

### 5.1 电机模块

`app_motor` 当前提供弱符号适配点：

```c
pendant_motor_hw_init()
pendant_motor_hw_play()
pendant_motor_hw_stop()
```

后续需要把主分支已有的 DRV2625 I2C 初始化和播放逻辑正式迁移到 `pendant/motor/app_motor.c`。

### 5.2 身份模块

`app_identity` 当前默认允许开发 fallback ID：

```c
#define APP_IDENTITY_ALLOW_DEV_FALLBACK 1
```

这样在没有烧录唯一识别码时也能生成 EID，便于先做互扫测试。

量产前必须关闭 fallback，改为唯一识别码不存在就进入错误状态。

### 5.3 Flash 分区

`app_storage` 当前默认 base 地址：

```c
#define APP_STORAGE_BASE_ADDR 0x70000
```

这个地址还没有最终确认，后续必须检查是否和 SDK 的 MAC、校准、pairing、OTA 区域冲突。

### 5.4 电池检测

`app_battery` 当前仍使用占位电压值，没有接真实 ADC。

后续需要接 PB1 ADC，并按硬件分压比例：

```text
ADC 电压 = 78.4% 电池电压
```

换算真实电池电压。

## 9. 第一阶段完成标准

第一阶段真正完成时，需要满足：

- 工程可编译。
- 设备上电后进入 `SYS_STATE_ADV_SCAN`。
- 设备周期发送 `PENDANT-ADV` Beacon。
- 另一块设备可以解析 Beacon。
- 附近设备表可以记录对端 EID。
- RSSI 达到 T1/T2/T3 并持续 Tin 后进入 S1/S2/S3。
- RSSI 低于阈值并持续 Tout 后逐级退出。
- 进入或退出等级时，马达按 1/2/3 次振动。
- 旧实验代码不再干扰新模块。
